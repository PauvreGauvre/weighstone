# Weighstone

CCINT is a header-only C++20 compiler-oriented integer computation toolkit.

**Publishing status:** The full implementation, CMake tests, 40-chapter manual, and MANIFEST.yaml have been produced as a downloadable `Weighstone.zip` in the associated ChatGPT conversation. The full archive has **not yet been synced to this repository**. The repository should not be regarded as the complete CCINT distribution.

Scope includes arbitrary-precision integers, bitvectors, exact rationals, modular arithmetic, abstract intervals, congruences, affine expressions and conservative proofs. Boost.Multiprecision is the numerical dependency.
